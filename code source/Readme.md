
# M.A.Y.A. – Code source de base

Ce dépôt contient le **code source de base de M.A.Y.A.**

Il correspond à la version du code installée sur les ordinateurs des utilisateurs via l’installateur officiel de M.A.Y.A.

## Installation

Le code source est installé localement sur l’ordinateur de l’utilisateur par l’installateur de M.A.Y.A.

Une fois installé, le code est **entièrement visible et accessible** sur l’ordinateur de l’utilisateur. Aucun fichier du code source n’est caché ou soumis à une restriction après installation.

## Éléments non inclus dans ce dépôt

Certains éléments nécessaires au fonctionnement complet de M.A.Y.A. ne sont pas présents dans ce dépôt.

### Node.js et Python

Les environnements **Node.js** et **Python portable** ne sont pas inclus dans ce dépôt.

Ils sont automatiquement installés et configurés par l’installateur de M.A.Y.A.

### Modèles VRM

Les fichiers VRM ne sont pas inclus dans ce dépôt.

L’installateur de M.A.Y.A. fournit **4 modèles VRM** :

* 2 modèles masculins
* 2 modèles féminins

Ces modèles sont installés séparément par l’installateur.

### Modèles LLM

Les **modèles LLM ne sont pas fournis** avec ce projet.

L’utilisateur doit fournir son propre modèle LLM compatible.

### Fichiers mmproj

Les **fichiers mmproj ne sont pas fournis** avec ce projet.

L’utilisateur doit également fournir les fichiers mmproj nécessaires à son modèle.

## Contenu du dépôt

Ce dépôt contient donc le **code source de base de l’application**.

L’installateur de M.A.Y.A. se charge de fournir et d’installer les éléments complémentaires nécessaires au fonctionnement de l’application, notamment les environnements Node.js et Python ainsi que les 4 modèles VRM.

Les modèles LLM et les fichiers mmproj restent à la charge de l’utilisateur.
